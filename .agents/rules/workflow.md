# Workflow Directives

1. **Git Commits**: Never commit or push code automatically. Only commit when the user explicitly instructs you to commit.
2. **Deployments**: Never deploy to Firebase Hosting or any remote host automatically. Only deploy when the user explicitly requests a deployment.
3. **Local Review & Testing**: Keep the app updated for local browser review on `localhost`. Never launch automated browser subagents or automated browser testing — the user performs all testing personally.
